# Blainoo AI Content Coach

A mobile-friendly dark theme landing page for **Blainoo AI Content Coach**, a tool concept for helping creators generate better ideas, scripts, hooks, and thumbnails.

## Files

- `index.html` contains the page structure, hero section, feature cards, and call-to-action button.
- `style.css` contains the responsive dark theme, blue and gold accents, card layout, and phone-friendly breakpoints.
- `script.js` adds a small interaction to the "Start Creating" button.
- `README.md` explains the project and how to preview or deploy it.

## Preview locally

Open `index.html` directly in a browser, or run a local static server from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy with GitHub Pages

1. Push this project to a GitHub repository.
2. In GitHub, open **Settings** for the repository.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch containing this folder and choose the folder that contains `index.html`.
6. Save the settings and wait for GitHub Pages to publish the site.
